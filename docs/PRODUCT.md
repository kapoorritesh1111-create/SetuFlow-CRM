# Setu Flow Product Contract

## Product Definition
Setu Flow is a trade execution system for import-export sales teams.

## Core Flow
Capture -> Lead -> Quote -> Order

## What Setu Flow Must Do
- Convert messy trade inputs into structured commercial records.
- Help sales teams move from inquiry to quote faster.
- Preserve control through approvals, locking, and auditability.
- Give management practical visibility into action, pipeline health, and geographic trade movement.

## Primary Modules
- Leads
- Quotes
- Orders
- Dashboard
- Admin

## Secondary Capabilities
These support the core flow and do not become separate top-level product areas:
- Capture / intake
- Pricing engine
- RFQ parsing
- Compliance checks
- Documents
- Contracts
- AI assist
- Share contact / My Card

## Product Rules
- No new top-level modules without deliberate product approval.
- No feature that bypasses the core flow unless it clearly supports the core flow.
- No duplicate paths for creating leads, quotes, or orders.
- No visual complexity that weakens trainability.

## Buyer Promise
Setu Flow must be credible to an enterprise buyer that wants one system for:
- inbound trade capture
- structured commercial workflow
- auditable quote creation
- order handoff and visibility

## Demo Standard
Every meaningful milestone must be able to demonstrate:
Capture -> Lead -> Quote -> Order
