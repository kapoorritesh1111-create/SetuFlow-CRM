# Setu Flow UX Rules

## UX Mission
Make the product trainable, predictable, and enterprise-safe.

## Core Principles

### 1. One Screen = One Decision
Each screen must have one dominant task. If a screen tries to be a dashboard, workspace, admin console, and assistant at the same time, it fails.

### 2. Guided Beats Flexible
Users should follow a guided operating path. Flexibility belongs in policy and admin settings, not in everyday workflows.

### 3. Reduce Surface Count
No return to command-center overload:
- no extra rails unless essential
- no stacked drawers for core work
- no duplicate inline workflow surfaces
- no parallel workspaces for the same entity

### 4. Make the Next Action Obvious
Leads should push toward Create Quote.
Quotes should push toward Review, Approve, or Send.
Orders should push toward execution readiness.
Dashboard should push toward immediate action.

### 5. Show System Intelligence, Hide System Complexity
Capture, pricing, RFQ parsing, and AI can be powerful, but their internal complexity should not spill into the user's working surface.

### 6. Enterprise Confidence Over Visual Drama
Confidence comes from clarity, consistency, and control. The interface should feel expensive because it is disciplined, not because it is crowded.
