# Setu Flow Leads and Capture Spec

## Purpose
Locked Sprint 1 screen and interaction reference for Leads and Capture.

## Core rules
- One screen = one decision
- Mobile and tablet must work before desktop polish
- No hover-only actions
- Capture is inbound intake only
- Outbound sharing belongs outside Capture
- Leads, Capture, and Quote must use the same inherited-context, rep-review, and approval-gate language

## Leads
- Qualified leads must clearly show when Draft Quote is available
- Quote preview must show inherited context before Quote entry opens
- Mobile uses sticky CTA behavior and tap-first quick actions

## Capture
- Reviewed records must clearly distinguish `Create Lead` from `Lead + Draft Quote`
- Duplicate and confidence states must stay visible before handoff
- Mobile uses sticky CTA behavior and simplified action priority

## Quote handoff
- Draft Quote must show inherited context from qualified Leads and reviewed Capture records
- Review-needed assumptions and approval cues must stay visible before send
