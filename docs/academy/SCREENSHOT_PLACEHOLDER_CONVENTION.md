# Screenshot Placeholder Convention

Use the exact filename shown on each Core Academy card.

- Prefix: `ACADEMY-`
- Sequence: three digits
- Description: lowercase kebab case
- Format: `.png`

Example:

`ACADEMY-020-quote-builder-send-gate.png`

Do not rename step IDs when replacing placeholders. Progress storage is keyed by the stable Academy step ID, while the screenshot filename can be replaced by the real asset using the same filename.
