# Admin organization help

Purpose: Use Admin Organization for setup and governance. It should not become the daily operating workspace.

## Best for

- Company profile, address, default country, default currency, markets, and countries.
- Default ports, payment terms, quote/order terms, and pricing defaults.
- Compliance rules, users, roles, invitations, and audit posture.
- Setup checklist guidance for new organizations.

## Common questions Setu Guru should answer

- What setup is missing before the team can quote?
- Which defaults affect products and quotes?
- Where should currency, country, market, ports, and terms be configured?
- Which actions require owner or admin approval?

## Common blockers

- Missing organization country, currency, market, address, or default terms.
- Pricing defaults not configured at organization or category level.
- Compliance rules do not separate quote-send from dispatch requirements.
- User roles do not match action permissions.
- Help text looks like sample data instead of guidance.

## Data sources

- Organization profile.
- Countries, markets, currencies, ports, terms, and pricing rules.
- Organization members, invitations, roles, and audit records.
- Document requirement rules and compliance policies.

## Allowed actions

- Explain setup gaps and safe next setup action.
- Route to company profile, pricing defaults, compliance rules, or people access.
- Recommend which default belongs at organization, category, or product level.
- Summarize role-based approval boundaries.

## Approval rules

Owner/admin approval is required for role changes, compliance policy changes, organization defaults, pricing default write-back, and destructive actions.

## Response policy

Keep admin answers focused on setup and governance. For daily work, route users back to Dashboard, Leads, Products, Quotes, Orders, or Compliance.
