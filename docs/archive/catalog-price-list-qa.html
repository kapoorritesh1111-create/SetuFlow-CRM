1. Visual workflow

Target happy path: Dashboard → Price Lists → Catalog Share Wizard → Buyer Link → Shared Links / Lead Activity → Quote Draft.
Use this exact flow for end-to-end QA before marking any Sprint 34 Catalog issue resolved.

2. Start after login: dashboard → correct nav item

1
From Dashboard
Use the primary navigation. For price-list setup, click Price Lists. For share and conversion testing, click Catalog.
Primary nav order includes Catalog and Price Lists. Start with Price Lists for setup, then Catalog for sharing.

3. Create the price list

Route: /price-lists. This screen has the heading Price Lists and a + Create Price List button in the top-right.
Create Price List opens a right-side drawer. The list cards are clickable for adding products later.

4. Add products and verify auto-fill

Click the price-list card, then + Add Product. Product selection auto-fills price, currency, MOQ, and lead time when source data exists.
FOB → fob_priceEXW/FCA → exw_priceCIF/CFR → cif_priceDDP/DAP → ddp/cif/fob fallback

5. Share catalog / send price list to buyer

Route: /catalog. Catalog Hub has + Add Product, + Create Price List, and Share Catalog. It also has tabs for Products, Price Lists, Shared Links, and Analytics.
Share Catalog opens a five-step drawer. The Setu Guru recommendation appears on Step 2 after products are selected.

6. Buyer-side test in private window

Open the copied link in a private/incognito window so you are acting like the buyer. If PIN was set, enter the PIN first.
Buyer room header actions are Request Quote, Ask a Question, and Download PDF. Product cards show prices or price-on-request.

7. Seller review and convert to quote

After buyer request, return to Catalog → Shared Links. Create Quote should open the quote draft generated from buyer selections.

8. Buyer-specific pricing foundation check

This final piece is an internal foundation only. It should not change buyer-facing share pricing or quote conversion yet.
