Dashboard Redesign — Code Review & Recommendations
What changed, what was removed, what was added, and why — written for handoff into the SETU Flow codebase. Every change maps to an existing component or prop.
1 — Section order rewrite (most impactful change)

❌ Current order (confuses operators)

1 WorkspaceWorkflowShell (today filter)
2 DashboardControlBar
3 ActionPriorityPanel
4 DashboardAiGovernance ← WAY too early
5 DashboardEvidenceCenter
6 DashboardTopStrip (KPIs)
7 World map
8 Action queue + risk
9 RecentActivityCard

✅ Proposed order (action-first)

1 KPI strip — numbers first
2 World map + Action queue (side-by-side)
3 Pipeline stages + Countries + Risk (3-col)
4 Activity feed (collapsed, below fold)
Why: Traders open the dashboard to know their number, then their actions. Putting AI governance above KPIs means the first thing a client sees in a demo is a chatbot disclaimer — not data. AI should collapse below fold entirely.
2 — Filter bar redesign
Label Was: "Leadership lens: All" — internal jargon nobody outside engineering understands → Now: "Viewing:" with clean select components. Plain language.
Time range Was: Missing entirely. Dashboard has no time period context. → Now: Add time range filter (This week / This month / This quarter / Custom). Critical for trading.
Filter UX Was: Small border-box labels stacked in DashboardControlBar — hard to scan at a glance. → Now: Each filter has a top micro-label (Market, Product, Stage) so the operator knows exactly what they're changing.
Active chips Was: Color-coded but only visible after interaction. Hard to tell what's filtered. → Now: Active chips appear next to filters inline. Result summary stays right-aligned ("12 markets · 47 leads").
Customize btn Was: "Customize" appears in the filter bar alongside filter controls — confusing purpose. → Now: Remove from filter bar. Move to a gear icon or profile menu. It's not a filter.
3 — Component changes
＋
Add
Time range filter
This week / This month / Quarter / Custom. Trading companies live by periods — the dashboard must reflect this. Add to DashboardFilters type and pass into all filtered queries.
＋
Add
KPI drill-through actions
Each KPI card should have a visible "→ Open Follow-up" micro-link. Clicking the KPI number navigates with the relevant filter pre-applied. Currently KPI cards link but the label is just "open detail" — not actionable.
＋
Add
Country table alongside map
The world map dot view is great. Add a compact table in the bottom row showing top countries by lead count + open quotes + pipeline value. Give traders a sortable data view, not just a visual one.
＋
Add
Pipeline value per stage
PipelineStageChartCard shows counts. Trading companies need value ($) per stage alongside count. Add a valueImpact sum to DashboardStageCount from the query layer — the bars stay but each row gets a value label.
✓
Keep & elevate
NeedsAttentionCard (action queue)
This is your best component. The severity bar, role chip, stage pill, and CTA button pattern is exactly right. Move it to the top of the page (beside the map, not below it) and give it max-height: 480px with scroll.
✓
Keep & elevate
World map with MarketCommandPanel
The click-to-drill pattern is strong. The map dot sizing by lead count is clear. Keep both. The improvement is sizing: give the map a fixed height of ~350px, not dynamic height. Right now it renders too short on large screens.
✓
Keep & elevate
Money at risk panel
Blocked value / At-risk value / Hot count — exactly what trading leadership wants to see. Problem: it's buried as a sidebar next to the action queue. Move it to the bottom-right card position where it has breathing room.
⟳
Restructure
DashboardTopStrip → role-filtered KPIs
The role-filtering logic (KPI_ROLE_MAP) is correct and should stay. The visual design needs: (1) a coloured top accent per intent, (2) a visible "→ action" link below the value, (3) move pipeline value to the KPI strip (it's currently only shown in the bottom section).
✕
Remove from dashboard
DashboardAiGovernance
This component surfaces at position 4 in the current render order — above the KPI strip. For a demo, this is a disaster: the first 400px a client sees is an AI disclaimer box. Move to a collapsible panel at the bottom, or to the /ai-suggestions page entirely.
✕
Remove / rename
"Leadership lens:" label in control bar
This appears as the first visible text in the filter bar. No client will understand it. Replace with "Viewing:" or remove the prefix entirely. The mode switch (All / Buyers / Suppliers) is self-explanatory.
✕
Remove from dashboard
DashboardEvidenceCenter
This is execution-layer detail (accepted orders, dispatch evidence). It belongs on the Orders page. Showing it on the dashboard adds complexity without dashboard-level value. Remove from dashboard — link to it from the KPI card instead.
✕
Demote
WorkspaceWorkflowShell today-filter tabs
The "Today / Week / Month" tab strip at the very top is duplicated by the time range filter in the control bar below. Having both creates confusion about which filter controls what. Consolidate into one time range selector in the filter bar.
4 — Sidebar & navigation
Sidebar Was: Collapsed to icon-only (96px) by default. Labels completely hidden. Users cannot identify where they are. → Now: Icon + micro-label (8px, 2-3 chars) always visible even in collapsed state. "Dash / Leads / Quotes / Orders" — readable without expanding.
Quick Lead Was: "＋ Quick Lead" only visible in the leads workspace toolbar. → Now: Move "＋ Quick Lead" to the top-right of the dashboard topbar. At a trade show, this is the one action operators need — it should be reachable from anywhere.
5 — Client demo readiness checklist
✓
Ready
World map is demo-impressive
Geographic coverage view with clickable countries is a strong differentiator. Keep it. Size it to at least 300px height on all screen sizes.
✓
Ready
Filter system is powerful
Market + Product + Stage + Status is the right filter set for trading. The URL sync (deep links) is a SaaS-quality feature. Show this in the demo — filter to one product and watch the map respond.
⟳
Fix before demo
Seed realistic demo data
The dashboard is data-driven. For demo: load 15-20 leads across India, UAE, Germany, UK, Singapore with varied stages, 3+ quotes, and 2 active orders. Empty state = unimpressive demo.
⟳
Fix before demo
Remove AI governance section from view
In a client demo, showing an AI disclaimer panel before KPIs raises questions you don't want. Either collapse it by default or remove it from the dashboard page entirely for the demo build.
🏆
Verdict: How close is this to world-class for trading companies?
The data architecture is excellent — filters, country insights, attention items, evidence items — it's all there. The world map with drill-down is genuinely differentiated and demo-worthy. The action queue with severity bars and role chips is the right mental model for trading operators.

What brings it from good → world-class: (1) flip the section order so KPIs land first, (2) push AI governance below the fold, (3) add value ($) to every pipeline stage, (4) add a time range filter, (5) add micro-action links on KPI cards so every number is a launchpad, not just a label. Make these five changes and this dashboard can hold its own against Salesforce trade editions.
