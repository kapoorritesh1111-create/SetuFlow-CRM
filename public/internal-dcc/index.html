How to tell whether a workflow is real

  • Core workflow: route sits in the main operating spine and the code shows progression, blockers, recovery, or gating.
  • Support surface: route helps visibility, intervention, reporting, or setup but is not itself the operating journey.
  • Mixed: repo has real logic but the page still reads more like system structure than intuitive user workflow.
  • Finish-pass rule: a module does not earn 96%+ just because the copy sounds good. It needs believable state coverage and operator recovery.
