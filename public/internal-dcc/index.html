Why Leads first: Leads now owns capture, qualification, coverage, quote prep, and the first entry into Quote Builder. It is the root of most operator work.
Why Quotes split in two: Quote Builder is a creation workflow from a lead; Quotes Workspace is an operating page for approval, status, versioning, and follow-up. They should not be one PR.
Why Orders is now first-class: Orders has a separate execution desk and state machine, so it needs its own PR rather than being hidden under Pipeline or Quotes.

Migration steps required:

  1. Add organization_id column to lead_markets, lead_product_interests, and contract_line_items
  2. Create foreign key constraints to organizations(id)
  3. Backfill existing rows by joining through parent tables (leads → organization_id)
  4. Add RLS policies on the new column for each table
  5. Add index: CREATE INDEX ON lead_markets(organization_id); etc.
  6. Re-test /ai-suggestions page — the "Some live data could not be loaded" banner should disappear
