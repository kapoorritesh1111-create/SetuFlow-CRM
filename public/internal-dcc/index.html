Gap 1

isCatalogPriceStale() built but never called — revise flow freshness warning missing

Root cause

isCatalogPriceStale() is fully implemented in src/lib/catalog-pricing-model.ts (line 573). It compares stored catalog_price_amount vs current product_prices.price for the same variant. But it is imported nowhere — not in quote-workspace.tsx, not in the revise flow, not anywhere.

Fix required

  • In quote-workspace.tsx: when opening the Revise flow, fetch current product_prices for all product_variant_ids in the existing line items
  • Call isCatalogPriceStale(lineItem, currentPrices) for each line item
  • If any return true, show a yellow banner: "Catalog price updated since v{version_no} — review before sending"
  • Do not block the revise flow — informational warning only

Files to change

  • src/features/quotes/components/quote-workspace.tsx — add freshness fetch + warning banner in revise path
  • No new schema needed — uses existing product_prices table

Confirmation

After fix: opening Revise on a quote where a product price has changed should show the yellow banner. If no prices changed, no banner shown.

Gap 2

FX lock badge missing in Quote Builder Edit mode

Root cause

quote-wizard-form.tsx has mode: "create" | "edit" prop (line 1239) but the FX rate lock badge — shown during Create — is not rendered when mode === "edit". The existing quote version's locked FX rate is not passed into the edit wizard or displayed.

Fix required

  • Pass the existing quote version's fx_rate (or equivalent field) as a prop to the wizard when in edit mode
  • In edit mode, show the FX lock badge with the locked rate (read-only, not re-fetched)
  • In revise mode: reuse the previous version's fx_rate — do not trigger a fresh rate fetch
  • Badge label: "FX locked — {rate} (from v{version_no})"

Files to change

  • src/features/quotes/components/quote-wizard-form.tsx — add lockedFxRate?: number | null prop, render badge when present
  • src/features/quotes/components/quote-workspace.tsx — pass locked fx_rate when opening Edit/Revise

Schema

Check quote_versions for fx_rate-equivalent column. The field may be stored in pricing_snapshot jsonb or a dedicated column. Audit the existing table before writing the prop.

Fix required

  • The form action calls uploadOrderDocument
  • Pass contract_id from the order record, requirement_code from the compliance item
  • After upload: revalidate the orders page to show updated compliance state
  • Show upload progress state (pending/uploaded/error) per item

Files to change

  • src/app/(app)/orders/page.tsx — replace Link with inline upload form per compliance item
  • src/features/orders/server/actions.ts — confirm uploadOrderDocument accepts requirement_code param (it does at line 179)

Dispatch gate

Separately: the "Mark delivered" / dispatch advance button must be disabled (with tooltip) when order.operationalControls.documentRequirementSummary.blockerCount > 0. The logic exists in dispatchGate() but the button is not conditionally disabled.
