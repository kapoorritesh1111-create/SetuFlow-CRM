Build Rules — Permanent

These rules apply to every future PR without exception. If a rule is violated, the PR must be rolled back.
Architecture Rules
  • Commercial truth is the center. AI, communication, integration, and hardening are subordinate.
  • Catalog/base price is always the default. Override requires a reason. Approval gates communication when threshold is crossed.
  • Orders admit only from accepted quotes. Contract continuity must preserve quote_id.
  • AI does not approve, dispatch, mutate record state, or invent commercial terms — ever.
  • Integrations mirror governed state. They do not create it.
  • Mobile = trade-event capture wedge only, until Pass 6 explicitly extends this.
Repo Rules
  • Never commit .orig, .bak, .diff, or patch files to the repo.
  • Never add files to META-INF or any Java-originated directory structure.
  • Never duplicate a data file — canonical location is src/features/{module}/data/. Import it; do not copy it.
  • Every new module added to src/features/ must have a DCC entry on the day it is created.
  • Every file in docs/ must be either active (current, buyer/operator relevant) or archived (moved to docs/archive/). No uncategorized files.
  • public/internal-dcc/ contains only index.html and the archive/ subfolder. Nothing else.
  • Reference HTMLs stay in public/reference-html/ — these are design references and are intentionally kept.
Security Rules
  • CSP unsafe-eval must stay absent from middleware; Pass 5 review confirms it is absent today.
  • Never expose service role key in client-side code.
  • All new RPC functions must be scoped to authenticated app users — no PUBLIC execution on workflow RPCs.
  • Add pin search_path=public to all new SECURITY DEFINER functions.
  • Rate limiting applies to all public API routes.
Design System Rules
  • Shell: 68px sidebar, 56px topbar, 24px route gutter.
  • No duplicate route hero panels or topbars that shift the shell grid.
  • Dashboard: route nav → filters → six stats → visual/kanban rhythm.
  • Mobile: MobileTabBar renders only on verified mobile-supported routes.
  • Shared components in src/components/ui/ — never duplicate them into a feature folder.
What This Repo Does Not Claim
  • External security audit
  • Automated production secrets rotation
  • WAF/rate limiting/SIEM at infrastructure layer
  • Fully mature communication-provider operations across all live vendors
  • Mobile-native parity
  • Large-scale production operating evidence
  • Signed contract readiness, dispatch, or completed order execution on live golden data
  • Live integration connector proof beyond mocks/proof-mode
