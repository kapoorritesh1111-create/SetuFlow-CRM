Brutal notes on what is still broken

1) Approval / Send is still conceptually weak

The nav label is better than the old hiding pattern, but the actual surface is still integration-native. An operator should feel like they are confirming outbound commercial movement, not supervising a connector control plane.

2) Orders / Execution is not yet one decisive desk

The continuity rule is good. The experience is still too spread across status, compliance, docs, and execution evidence. That fragmentation will still show up in demos.

3) Follow-up still carries too much product truth

Leads is powerful, but still too much of the system is encoded there. The user still has to think hard to know what to do next and what belongs elsewhere.

4) Catalog is governed but not elegant

The pricing contract is one of the strongest differentiators in the repo. The UX around it still feels like serious admin software instead of crisp trade software.

5) AI is still a sidecar

Bounded is good. Peripheral is not. Useful AI should reinforce decisions where the operator is already working, not sit as a parallel helper lane.

6) The shell is no longer the excuse

That is good news and bad news. The next embarrassment is now inside the working surfaces. Future passes must compress, clarify, and remove internal-tool residue.
