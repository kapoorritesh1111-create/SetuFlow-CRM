Resolution Guide Known patterns & how to fix them — use for ChatGPT dev handoff
ⓘ
All fixes below are based on the Pass 21 TypeFix codebase. Reference file paths are relative to src/. Hand these to your ChatGPT dev session with the specific test result notes.
P0 — Critical

Dashboard KPIs return null / undefined / 0 for all values

1
Root cause: Dashboard data loader (features/dashboard/logic/) or the render function in app/(app)/dashboard/_lib/render-dashboard-page.tsx failing to fetch from Supabase with correct org/membership context.
2
Check: Open browser DevTools → Network tab. Reload dashboard. Look for any 400/401/500 errors on Supabase REST calls. Note the exact query path and error code.
3
Fix: In the failing server function, verify workspace.organization.id and workspace.membership.id are being passed to all queries. Check RLS policies in Supabase dashboard allow the current role to SELECT from the relevant tables (leads, quotes, pipeline_stages).
4
Dev prompt for ChatGPT: "The SETU Flow dashboard KPI cards return 0/null. Check src/features/dashboard/logic/ and src/app/(app)/dashboard/_lib/render-dashboard-page.tsx to ensure workspace context is correctly threaded into all Supabase queries. Also verify RLS allows the current user role."
P0 — Critical

Lead Command Center — page crashes / blank on load

1
Root cause: features/leads/command-center/LeadCommandCenterPage.tsx — a required prop (snapshot, availableProducts, etc.) is being passed as undefined. Or a TypeScript type error on QuotePricingBasis or LeadProfileSnapshot causing runtime crash post-compilation.
2
Check: Console error in DevTools will say which prop is undefined or which function threw. Look for normalizePricingBasis or openOrCreateLeadQuoteDraft errors specifically.
3
Fix: In the server page (app/(app)/leads/[leadId]/page.tsx), add null-guards before passing data to LeadCommandCenterPage. Default arrays to [] and objects to valid empty shapes matching LeadProfileSnapshot type.
4
Dev prompt: "Lead Command Center crashes on load. Check src/app/(app)/leads/[leadId]/page.tsx server component for null prop risks. Verify all props passed to LeadCommandCenterPage match the expected types in src/features/leads/command-center/types.ts."
P1 — High

Stage move on Pipeline Strip does not update / throws error

1
Root cause: moveLeadToStage server action in features/pipeline/server/actions.ts not being called correctly, or Supabase UPDATE on leads.stage_id failing due to RLS.
2
Check: After clicking a stage in the strip, watch Network for any POST to the server action. If 401/403: RLS issue. If 500: action code error. If no request at all: client-side JS error in LeadPipelineStageStrip.tsx.
3
Dev prompt: "Stage move via pipeline strip fails. Debug the moveLeadToStage server action in src/features/pipeline/server/actions.ts and the click handler in src/features/leads/command-center/LeadPipelineStageStrip.tsx."
P1 — High

Quote Builder wizard loses data on back navigation

1
Root cause: Quote wizard state is likely managed in component-local state without persistence. Going back unmounts the step component and loses data.
2
Fix approach: Lift quote draft state to a parent context/store. Or auto-save draft to Supabase on each step transition so back-navigation rehydrates from DB.
3
Dev prompt: "Quote Builder loses form data when clicking Back. The wizard in src/app/(app)/leads/[leadId]/quote/page.tsx needs state persistence across steps. Either lift state to a parent context or auto-save to Supabase on each step. Use the openOrCreateLeadQuoteDraft server action."
P1 — High

Admin Users — role change not saving / showing error

1
Root cause: updateMemberRole or updateInvitationRole server actions in features/admin/server/actions.ts failing. Could be owner-role guard blocking the update, or RLS on organization_members table.
2
Check: The canManageOwners flag controls whether the Save button appears. If role is Owner-protected and current user is not Owner, the UI correctly shows warning. If normal roles fail: check server action error response.
3
Dev prompt: "Role update fails in Admin Users. Debug updateMemberRole in src/features/admin/server/actions.ts. Verify the canManageOwners gate logic and that Supabase RLS allows UPDATE on organization_members for admin role."
P2 — Medium

Products spreadsheet — API 500 on save or spreadsheet fails to load

1
Root cause: app/api/products/route.ts or app/api/products/spreadsheet/route.ts throwing on Supabase query. Possible type mismatch on products table fields per Pass 21 TypeFix.
2
Dev prompt: "Products spreadsheet fails to save. Check src/app/api/products/route.ts and src/app/api/products/spreadsheet/route.ts. Verify field names match the products table schema from Complete Schema.txt. Ensure TypeScript types in src/types/products.ts are correct after Pass 21 TypeFix."
P2 — Medium

Activity Composer — note submission silently fails

1
Root cause: ActivityComposerCard.tsx submit handler calling a server action that fails quietly. The UI optimistically adds the note but the DB write fails.
2
Fix: Add error handling with toast notification on the server action response. Verify lead_activities table INSERT RLS allows the current user. Check lead_id is being passed correctly in the activity payload.
3
Dev prompt: "Activity notes appear to save but disappear on reload. Check src/features/leads/command-center/activity/ActivityComposerCard.tsx server action call and the lead_activities table INSERT. Add error toast if write fails."
P3 — Low

World map not rendering / blank gray box

1
Root cause: features/dashboard/components/world-coverage-map.tsx — the SVG/canvas map library not initializing, or GeoJSON data failing to load.
2
Dev prompt: "World map on dashboard shows blank. Check src/features/dashboard/components/world-coverage-map.tsx — verify the map rendering library initializes correctly client-side and GeoJSON country data loads. Check for hydration errors in console."
