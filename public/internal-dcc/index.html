Root cause of all 3 Vercel errors: 2-argument server actions (useFormState pattern) used as direct form action= props which require 1-argument. The fix pattern is always the same: create a 1-arg wrapper.

The fix pattern for future reference

// 2-arg (useFormState pattern) — CANNOT be used as form action=
export async function saveX(_: State, formData: FormData): Promise<State> { ... }

// 1-arg wrapper — CAN be used as form action={saveXAction}
export async function saveXAction(formData: FormData): Promise<void> {
  await saveX(undefined, formData);
}
