Catalog Redesign — Code Review & Builder Guide
The catalog is functionally solid — products, variants, pricing, and the spreadsheet view all exist. The problems are navigability (mode switch confusion), the "gap" concept being unexplained, and the buried pricing UX. These changes surface pricing gaps immediately, make the product detail a proper 5-tab drawer, and add a clean 3-step wizard for new products.
1 — What changed in the product table
＋
New
Category group headers in table
Products are now grouped by category with a coloured header row between groups. Eliminates the need to filter by category to find products. Color-coded dot per row for quick scan. Builder: add a section divider row between category groups in products-table.tsx renderRows().
＋
New
Three price columns visible (Ex-Factory / FOB / CIF)
Current: one "Latest price" column. New: three price columns per row, each inline-editable in unit mode. Missing = "— add" in faded text. Builder: add ex_factory, fob, cif columns to products-table-columns.ts with EditablePriceCell per column.
⟳
Fix
Gap badge replaces "gap filter" concept
Current: "Has gap / Complete" filter requires the user to know what a gap is. New: visible gap badge on every row (✓ 9/9 markets / ⚠ 6/9 / ✕ 0/9). The ⚠ tab filters to gap products. No filter needed. Replace products-gap-badge.tsx with this inline badge.
⟳
Fix
Mode switch — Products / Pricing / Spreadsheet
Implemented in PR-NS-07: Catalog now exposes Products / Pricing view / Spreadsheet labels, keeps inline USD baseline editing in Pricing view, and preserves the product drawer plus add-product wizard.
2 — Product detail drawer: 5 tabs instead of 1
✓
Keep
3-step wizard for Add Product
The WizardShell with Basics / Details / Review steps is the right pattern. Keep it. The main improvement: make the step labels more descriptive and add a progress indicator that visually shows which step you're on. Basics → Details → Review is already intuitive.
＋
New
Product detail with 5 tabs
Current ProductDetailDrawer has a flat form for name/brand/description/isActive. New: 5 tabs — Overview (edit basics), Pricing (market price table, inline editable), Variants (add/edit pack formats), Trade attrs (HSN, origin, certs), History (audit log). This replaces AuditHistoryDrawer as a separate drawer.
＋
New
Inline price editing with market rows
The pricing tab shows a table with one row per market, three editable price columns (Ex-Factory / FOB / CIF), and a Save button per row. This replaces the distributed pricing UI in products-manager.tsx. Builder: move the CatalogPricingDraft save logic into the drawer Pricing tab component.
✕
Remove
AuditHistoryDrawer as separate component
Currently a separate drawer opened from the product card. Move audit history into the History tab of the product detail drawer. One drawer, all context. Removes the second overlay and the extra "Audit history" CTA from the product row actions.
3 — View tabs: replace invisible mode switch
⟳
Fix
Category tabs replace the dropdown filter
Current: category is a dropdown inside the toolbar. New: horizontal tabs across the top (All / Snacks / Powders / Sweeteners / Onion & Garlic / Freeze-dried / ⚠ Gaps). Active tab shows count. Builder: render these as page-nav tabs that drive the category filter state.
＋
New
6-stat strip above the table
Total products / Quote-ready / Pricing gaps / Variants / Inactive / Active markets. Same 6-card strip pattern from dashboard and pipeline. Each card is clickable and filters the table. Builder: build as shared PipelineStatsStrip — same component, different props.
▦
Builder sprint plan — Catalog page
Sprint 1 (quick — 1 day): Add category group headers to table · Add gap badge (✓/⚠/✕ markets) per row · Add Ex-Factory + FOB + CIF columns · Rename mode switch labels from "products/catalog" to "Products/Pricing/Spreadsheet".

Sprint 2 (core — 2 days): Expand ProductDetailDrawer to 5 tabs (Overview, Pricing, Variants, Trade attrs, History) · Move pricing edit into Pricing tab · Move audit history into History tab · Remove AuditHistoryDrawer as separate drawer.

Sprint 3 (polish — 1 day): Add 6-stat strip · Add category tabs (replacing dropdown) · Replace filter toolbar with filter bar (consistent with dashboard/leads/pipeline).
