# Core Academy Screenshots

Upload Core Setu Flow Academy screenshots into this folder using the exact filenames defined in:

`src/features/academy/core-academy-content.ts`

Example:

`ACADEMY-001-global-navigation.png`

Public URL:

`/academy/core/screenshots/ACADEMY-001-global-navigation.png`

The Academy tries this path automatically. When an image is not present, it displays the exact expected filename and upload location instead.

Rules:

- Keep the `ACADEMY-###-description.png` filename unchanged.
- Use PNG format.
- Do not upload Core screenshots into Packaging Academy folders.
- Replacing a screenshot does not require changing the Academy step ID.
