Product

SETU Flow CRM

A trade-focused commercial operating system for export-led businesses. Manages the full lifecycle from lead capture through versioned pricing, approval-gated quote delivery, order execution, and payment closeout.

Platform
SaaS · Multi-tenant
Each organisation gets isolated data, custom pipelines, roles, and module access controls.
Primary users
Sales · Ops · Leadership
Sales manages leads and quotes. Ops executes orders. Leadership monitors KPIs and pipeline health.
Field capture
Mobile-first additive
Phone surfaces support trade-show scan, vCard sharing, and lead capture without compressing desktop pages.
AI assist
Reviewable — not auto-send
Setu Guru generates draft suggestions. Every AI action requires explicit operator review before anything goes out.

Core Design Principles

PrincipleWhat it means in practice
Gate-enforced flowNo quote can be sent without approval clearance. No order can execute without an accepted quote. Every stage transition is logged.
Commercial immutabilityOnce a quote version is sent, it is locked. Orders always trace back to the accepted version. Quote line items are never retroactively changed.
Integration-ready architectureFinance, freight, and messaging adapters are built as queue-backed boundaries. External providers connect to the queue — no direct coupling.
AI is a reviewer's toolThe AI assistant (Setu Guru) drafts and suggests. The system never auto-sends AI-generated content. All AI decisions are stored for audit.
Mobile is additivePhone captures feed into the CRM. The mobile experience is purpose-built for field actions, not a compressed desktop view.

Workflows

Commercial Workflows

Every deal flows through six stages in sequence. No stage can be skipped without explicit gate approval. The system enforces these gates at the database level.

01
Capture
/scan · /trade-events
Business card scan or manual entry. Raw contact becomes a qualified lead.
02
Qualify
/leads
Assign owner, add product interests, set market, plan follow-up. Quote gate opens when ready.
03
Quote
/quotes
Build versioned quote with freight, FX, and pricing rules. Override >15% triggers approval.
04
Approve & Send
/approval-send
Internal approval → compliance check → PDF sent via email or WhatsApp. Quote locked on send.
05
Execute
/orders
Actual lines, proforma, packing, freight, processing, dispatch. Each stage gate-approved.
06
Close
/orders
Final invoice, payment reference, reconciliation, archive. Five closeout checks required.

AI

Setu Guru — AI Integration

Context-aware AI copilot embedded in every authenticated page. Generates reviewable drafts and suggestions. Explicitly prevented from taking autonomous actions.

🤖
What is Setu Guru?
A context-aware AI copilot built directly into the CRM workspace. It reads the current route, organisation context, and user role to provide relevant help — lead qualification guidance, quote drafting suggestions, compliance reminders, and data lookups. Every AI action is reviewable, logged, and requires operator confirmation before anything is sent or saved.
User asks Guru → AI generates draft / suggestion → Operator reviews → Operator confirms or dismisses → Action recorded in ai_suggestions

What Guru Can Do

📋
Lead Qualification Help
Suggests qualification criteria, flags missing product coverage, and recommends follow-up timing based on lead stage and activity history.
💬
Quote Drafting
Drafts introductory and quote cover messages based on the lead's company, region, product interests, and quote value. Operator reviews before sending.
📊
Dashboard Interpretation
Explains current KPI state, identifies overdue follow-ups, and surfaces priority actions based on what's visible on the current screen.
🔍
Compliance Guidance
Answers questions about document requirements, waiver rules, and what each compliance gate means. Does not auto-resolve blockers.
📦
Order & Document Help
Guides operators through execution stages, explains what each gate requires, and drafts document cover text for proforma invoices and packing notes.
🔎
Live Research (Optional)
Can search for market information, company background, or trade regulations. Research results are surfaced as suggestions — not automatically written into records.

AI Guardrails — What Guru Cannot Do

🚫 Never auto-sends — Guru cannot send emails, WhatsApp messages, or quote PDFs. All sends require operator action.
🚫 Never modifies records autonomously — Guru cannot update leads, approve quotes, change order lines, or modify any database record without explicit operator confirmation.
🚫 Never bypasses gates — Guru cannot waive compliance blockers, approve overrides, or clear order gates. These are always human decisions.
✅ All AI decisions are stored — every Guru suggestion and operator decision (accepted / dismissed) is written to ai_suggestions with a full audit trail.
✅ Configurable per org — model, daily token budget, feature toggles (live research, compliance help, draft messages) are controlled per organisation at /admin/guru-config.

Security Architecture

Row Level Security
RLS enabled on all active tables. Multi-tenant isolation enforced at the Postgres layer. Every query is filtered by organization_id policy.
Role-Based Access
10 permissions across Leads, Quotes, Orders, and Admin modules. Roles are org-scoped and editable via the visual permission matrix at /admin/roles.
RPC Hardening
SECURITY DEFINER RPCs have anon EXECUTE revoked. All functions have explicit search_path set. Advisor-flagged follow-ups tracked in backlog.
API Keys
Scoped keys with SHA-256 hash storage. Only the prefix is stored; raw key shown once at generation. Revokable with full audit trail at /admin/api-keys.
ℹ
Ongoing hardening work Several RLS-enabled tables have policies in progress. The active_product_pricing_rules_v view is flagged as security-definer and under review. A dedicated database hardening migration covers these before full multi-client production release.

Quick Reference

Condensed workflow rules, CTAs, blockers, and system constraints for each major module.

Lead WorkflowGoal: Move captured contact into quote-ready state

Key CTAs

  • Open
  • More → Continue quote
  • Open coverage manager
  • Compliance check
  • Attach evidence
  • Waive for quote
  • Defer to dispatch
  • Create quote

Key Blockers

  • No product coverage saved
  • Lead is disqualified
  • Missing country/market
  • Missing follow-up date
  • Compliance evidence missing
  • Advisory dispatch doc mistaken for quote blocker
Quote Build & SendGoal: Create and send a clean commercial offer

Key CTAs

  • Create quote
  • Add product
  • Save draft
  • Send quote
  • Open customer PDF
  • Mark accepted
  • Mark rejected
  • Approve & allow send

Key Blockers

  • Missing products/currency
  • Approval pending
  • Compliance evidence missing
  • No FX snapshot
  • No current version or line items
  • Send blocker flag active
Quote VersioningGoal: Keep quote history clean and auditable

Version States

  • Draft — editable
  • Needs approval — blocked
  • Sent — LOCKED
  • Accepted — LOCKED → order source
  • Rejected — LOCKED
  • Superseded by vN

Key Rules

  • Revise instead of editing locked versions
  • current_version_id ≠ accepted_version_id
  • Orders start from accepted_version_id only
  • Earlier versions stay readable
Order ExecutionGoal: Turn accepted quote into controlled execution

Key CTAs

  • Open, Prepare actual lines
  • Save, Add line, Remove
  • Approve actual lines
  • Prepare / Preview / Approve document
  • Send tracked
  • Download / Print PDF

Key Blockers

  • No accepted quote lineage
  • Actual lines not approved
  • Document not approved before external send
  • Packing not approved before freight
  • Processing incomplete before dispatch
  • Blocking trade requirements open
Document Send TrackingGoal: Track every document send per recipient with open analytics

Key CTAs

  • Send tracked (email / WhatsApp)
  • Preview
  • Download / Print PDF
  • Copy link
  • View history
  • Send again

Status Meanings

  • link_created — tracked link generated
  • previewed — preview-only link opened
  • link_opened — recipient accessed link
  • NOT ≡ provider-confirmed delivery
Finance & CloseoutGoal: Close the order after invoice, payment, reconciliation, and archive

Key CTAs

  • Prepare final invoice
  • Approve invoice
  • Send final invoice again
  • Generate receipt + close
  • Download archive

Key Blockers

  • Final invoice not approved
  • Payment not received
  • Reconciliation incomplete
  • Outstanding amount above zero
  • Archive not confirmed
