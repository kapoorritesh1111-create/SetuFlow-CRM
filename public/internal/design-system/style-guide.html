Governance

The rules that keep this from decaying back into 95 unique hex values.

  1. No [#hex] colors, no rounded-[…], no tracking-[…], no inline style colors in src/app or src/features. If a token is missing, add the token.
  2. Weights 400–700 only in product UI; 800–900 are marketing display.
  3. Status-like UI goes through a semantic mapper (getStatusTone, getQuoteTone, getComplianceTone) — never local class strings.
  4. globals.css holds resets and token imports only. No !important patches targeting DOM shape — fix the component.
  5. Enforce with a grep-based design-tokens.test.mjs in the existing test suite, failing on regressions in changed files.
